# Text Summarizer (T5 + FastAPI)

A dialogue summarization system that fine-tunes a T5 transformer model on the SAMSum dataset to generate concise summaries of conversations, deployed as a web app using FastAPI.

## Overview

This project fine-tunes **T5-small** (a pretrained transformer from Hugging Face) on the SAMSum dataset — a collection of messenger-style conversations paired with human-written summaries — to build a model that can summarize dialogue into a short, readable paragraph. The trained model is served through a FastAPI backend with a simple web interface for real-time summarization.

## Problem Statement

Long conversations (customer support chats, group messages, meeting transcripts) are time-consuming to read in full. This project builds a model that takes raw dialogue as input and generates a concise, accurate summary — reducing a multi-turn conversation into a few sentences.

## Dataset

**SAMSum Dataset** — a public dataset of ~16,000 messenger-style conversations, each paired with a human-written summary.

- Training samples used: 4,000 (randomly sampled)
- Validation samples used: 500 (randomly sampled)
- Not included in this repo due to size — available on [Hugging Face Datasets](https://huggingface.co/datasets/samsum)

## Workflow

1. **Data Loading** — Load train/validation splits from CSV.
2. **Text Cleaning** — Normalize line breaks, whitespace, strip HTML tags, lowercase text.
3. **Tokenization** — Tokenize dialogues (max length 512) and summaries (max length 150) using `T5Tokenizer`.
4. **Model Fine-Tuning** — Fine-tune `t5-small` using Hugging Face's `Trainer` API.
5. **Model Saving** — Save the fine-tuned model and tokenizer locally.
6. **Inference** — Generate summaries for new dialogue using beam search.
7. **Deployment** — Serve the model through a FastAPI backend with an HTML/JS frontend.

## Model & Training Details

| Parameter | Value |
|---|---|
| Base Model | T5-small |
| Epochs | 3 |
| Batch Size | 3 (train & eval) |
| Weight Decay | 0.01 |
| Warmup Steps | 400 |
| Final Training Loss | 0.762 |
| Hardware | Tesla T4 GPU |

## How to Run

**1. Train the model** (or use a saved checkpoint):
```bash
jupyter notebook text_summarizer.ipynb
```

**2. Run the web app:**
```bash
pip install fastapi uvicorn transformers torch
uvicorn app:app --reload
```

**3. Open in browser:**
```
http://127.0.0.1:8000
```

Paste any dialogue into the text box and get an instant summary.
